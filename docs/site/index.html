02 / HOW IT WORKS

One prompt.
A loop that delivers.

Bob Shell executes the task. The harness coordinates the process and checks the result with a command you define.

Explore orchestration
01

Execute

Your prompt arrives through the API. Bob works inside the container and produces the result.

bob run <prompt>
02

Verify

The harness runs your validation command. An exit code of 0 means success.

check: "pytest -q"
03

Improve

If validation fails, Bob receives the error and retries up to your configured limit.

max_attempts: 3

You define what “done” means. The harness handles the loop.Available with POST /run and scheduled tasks. Slack uses /jobs.

03 / FOR DEVELOPERS

From your code
to action.

A simple REST interface for Bob Shell. Connect the agent to the tools and language you already use. 

# Execute, verify, and retry
curl -X POST http://localhost:8080/run \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "Implement add() in calc.py",
    "check": "pytest -q",
    "max_attempts": 3,
    "workdir": "/workspace"
  }'
# pip install requests
import requests

response = requests.post(
    "http://localhost:8080/run",
    json={
        "prompt": "Implement add() in calc.py",
        "check": "pytest -q",
        "max_attempts": 3,
        "workdir": "/workspace",
    },
    timeout=30,
)
response.raise_for_status()
print(response.json())
const response = await fetch(
  'http://localhost:8080/run', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      prompt: 'Implement add() in calc.py',
      check: 'pytest -q',
      max_attempts: 3,
      workdir: '/workspace'
    })
  }
);
if (!response.ok) throw new Error(response.status);
console.log(await response.json());

04 / QUICKSTART

Your next idea
starts here.

You need Git, Podman or Docker, and an IBM Bob API key. Slack is optional.

  1. 01

    Clone and configure

    Copy the template and add your key to BOBSHELL_API_KEY. 

    git clone https://github.com/BrUn3y/remote_bob.git
cd remote_bob
cp .env.example .env
    Get an API key
  2. 02

    Start the container

    Start the API and, if you configured its tokens, the Slack bot. 

    podman compose up --build -d
    Your files persist in ./workspace.
  3. 03

    Check and explore

    Check the status and open Swagger at localhost:8080/docs. 

    curl http://localhost:8080/health
    Your API runs on port 8080.
i

The unrestricted-dev mode allows commands to run inside the container. Use it in an isolated environment, with trusted Slack channels and the API accessible only from localhost. Review security configuration
