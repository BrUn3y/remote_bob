01 / CAPACIDADES

Menos pasos.
Más posibilidades.

El poder de Bob Shell, con las conexiones que necesitas para llevar tus ideas al siguiente paso.

CONECTA

Una API, múltiples caminos

Envía prompts desde cualquier aplicación. Elige ejecución síncrona, trabajos en segundo plano o streaming.

/invoke · /jobs · /stream ORQUESTA

Resultados que se verifican

Define una comprobación. El harness ejecuta, valida y devuelve el error a Bob para un nuevo intento.

/run COLABORA

Tu equipo, en el mismo hilo

Habla con Bob desde Slack. Conserva el contexto, comparte archivos y cancela tareas sin salir de la conversación.

02 / CÓMO FUNCIONA

Un prompt.
Un ciclo que avanza.

Bob Shell ejecuta la tarea. El harness coordina el proceso y comprueba el resultado con el comando que tú defines.

Conocer la orquestación
01

Ejecutar

Tu prompt llega por la API. Bob trabaja en el contenedor y genera el resultado.

bob run <prompt>
02

Verificar

El harness ejecuta tu comando de validación. Un código de salida 0 indica éxito.

check: "pytest -q"
03

Mejorar

Si la validación falla, Bob recibe el error y reintenta hasta el límite configurado.

max_attempts: 3

Tú defines qué significa “listo”. El harness se encarga del ciclo.Disponible en POST /run y tareas programadas. Slack utiliza /jobs.

03 / PARA DESARROLLADORES

De tu código
a la acción.

Una interfaz REST sencilla sobre Bob Shell. Integra el agente con las herramientas y el lenguaje que ya usas. 

# Ejecuta, verifica y reintenta
curl -X POST http://localhost:8080/run \
  -H 'Content-Type: application/json' \
  -d '{
    "prompt": "Implementa add() en calc.py",
    "check": "pytest -q",
    "max_attempts": 3,
    "workdir": "/workspace"
  }'
# pip install requests
import requests

response = requests.post(
    "http://localhost:8080/run",
    json={
        "prompt": "Implementa add() en calc.py",
        "check": "pytest -q",
        "max_attempts": 3,
        "workdir": "/workspace",
    },
    timeout=30,
)
response.raise_for_status()
print(response.json())
const response = await fetch(
  'http://localhost:8080/run', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      prompt: 'Implementa add() en calc.py',
      check: 'pytest -q',
      max_attempts: 3,
      workdir: '/workspace'
    })
  }
);
if (!response.ok) throw new Error(response.status);

04 / INICIO RÁPIDO

Tu siguiente idea
empieza aquí.

Necesitas Git, Podman o Docker y una API key de IBM Bob. Slack es opcional.

  1. 01

    Clona y configura

    Copia la plantilla y agrega tu clave en BOBSHELL_API_KEY. 

    git clone https://github.com/BrUn3y/remote_bob.git
cd remote_bob
cp .env.example .env
    Obtener una API key
  2. 02

    Levanta el contenedor

    Inicia la API y, si configuraste sus tokens, el bot de Slack. 

    podman compose up --build -d
    Los archivos persisten en ./workspace.
  3. 03

    Comprueba y explora

    Consulta el estado y abre Swagger en localhost:8080/docs. 

    curl http://localhost:8080/health
    Tu API está en el puerto 8080.
i

El modo unrestricted-dev permite ejecutar comandos en el contenedor. Úsalo en un entorno aislado, con canales de Slack de confianza y la API accesible solo desde localhost. Revisar configuración de seguridad
